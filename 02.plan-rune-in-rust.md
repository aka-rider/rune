### Buffer decision — port Go's `String + line_starts`, NOT ropey

Go reference: `pkg/editor/buffer/buffer.go:32-36` — `Buffer{content string, lineStarts []int, version uint64}`, immutable value semantics; `ApplyEdits(edits) -> (Buffer, []AppliedEdit, error)` requires edits sorted descending & non-overlapping, validates UTF-8 char boundaries on every edit boundary (`buffer.go:128-136`), returns `AppliedEdit{Start, End, Deleted, Insert}` (deleted text kept for inversion).

Rationale: (1) comrak takes `&str` and the pipeline reparses the whole buffer per content change — a rope would be flattened to `String` every keystroke anyway; (2) byte-offset semantics are load-bearing everywhere (§1.5) and the Go clamp/validation behavior is fuzz-proven — port it 1:1 so the Go test corpus is reusable; (3) the public API is a chokepoint behind which ropey can be swapped later if profiling demands.

```rust
// rune-core/src/buffer.rs
pub struct Edit { pub start: usize, pub end: usize, pub insert: String, pub cursor_id: u32 }
pub struct AppliedEdit { pub start: usize, pub end: usize, pub deleted: String, pub insert: String }
#[derive(Clone)]
pub struct Buffer { content: String, line_starts: Vec<usize>, version: u64 }
impl Buffer {
    pub fn from_bytes(b: Vec<u8>) -> Result<Buffer, BufferError>;   // String::from_utf8 — refusal point
    pub fn apply_edits(&self, edits: &[Edit]) -> Result<(Buffer, Vec<AppliedEdit>), BufferError>;
    // insert/delete/replace wrappers; line_count/line_start/line_end/line;
    // offset_to_line_col / line_col_to_offset; char-boundary clamping helpers (§1.3)
}
```
Errors are a `BufferError` enum (out-of-bounds, splits-char, overlapping, invalid-utf8) — never panic.

### The element HSM hierarchy (centerpiece — implement these types)

Replaces Go's flat span list + stateless `shouldReveal` (`pkg/editor/display/span_metadata.go:4-22`) with a typed machine tree.

```rust
// rune-md/src/element/mod.rs
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum RevealState { Rendered, Revealed }

/// Embedded in every concealable element. `transition` is the ONLY writer of
/// `state` in the crate (image.go:191-243 pattern). Returns true iff changed.
#[derive(Clone, Copy, Debug)]
pub struct RevealSm { state: RevealState }
impl RevealSm {
    pub fn state(&self) -> RevealState;
    pub fn transition(&mut self, next: RevealState) -> bool;
}

/// Parent → child reveal directive (the reveal-inheritance carrier).
pub enum RevealGrant { Decide, ForceRevealed, ForceRendered }

pub struct ByteRange { pub start: usize, pub end: usize }     // half-open, absolute bytes

/// Precomputed once per sync from CursorSet + Buffer.
pub struct CursorProbe { /* offsets + BufferPoints */ }
impl CursorProbe {
    pub fn any_on_line(&self, line: usize) -> bool;
    pub fn any_in(&self, r: ByteRange) -> bool;               // offset ∈ [start, end)
    pub fn any_in_lines(&self, first: usize, last: usize) -> bool;
}

/// The inherited context every parent hands its children. Downstream elements
/// NEVER own wrap or focus state — they read the root's through this.
pub struct InheritCtx<'a> {
    pub focus: DocState,
    pub wrap: &'a WrapState,      // root-OWNED, inherited (user directive)
    pub grant: RevealGrant,
    pub cursors: &'a CursorProbe,
}
impl<'a> InheritCtx<'a> {
    /// THE "downstream inherits upstream state" rule, in one function.
    pub fn child(&self, own: RevealState) -> InheritCtx<'a> {
        let grant = match (self.grant, own) {
            (RevealGrant::ForceRendered, _) => RevealGrant::ForceRendered,
            (_, RevealState::Revealed)      => RevealGrant::ForceRevealed,
            (g, RevealState::Rendered)      => g,
        };
        InheritCtx { grant, ..*self }
    }
}
```

Every element's `sync(&mut self, ctx: &InheritCtx) -> bool` has one fixed shape — decide → transition → propagate:

```rust
let want = match ctx.grant {
    RevealGrant::ForceRendered => RevealState::Rendered,
    RevealGrant::ForceRevealed => RevealState::Revealed,
    RevealGrant::Decide        => /* per-element policy, table below */,
};
let mut dirty = self.sm.transition(want);
let child_ctx = ctx.child(self.sm.state());
for c in &mut self.children { dirty |= c.sync(&child_ctx); }
dirty
```

Root machine:

```rust
// rune-md/src/element/doc.rs
pub enum DocState { Unfocused, Focused }
pub struct WrapState { pub width: u16 }        // root-owned; only DocMachine mutates it

pub struct DocMachine {
    state: DocState, wrap: WrapState, blocks: Vec<Block>,
    built_version: u64, dirty: bool,
}
impl DocMachine {
    fn transition(&mut self, next: DocState) { let prev = self.state; self.state = next; self.enter_state(prev); }
    fn enter_state(&mut self, _prev: DocState) { self.dirty = true; }
    pub fn set_focus(&mut self, focused: bool);
    pub fn set_width(&mut self, width: u16);   // wrap change; dirty; NO reveal transitions
    pub fn sync_content(&mut self, buf: &Buffer);   // rebuild tree via comrak iff version changed
    pub fn sync_cursors(&mut self, buf: &Buffer, cursors: &CursorSet);  // the ONLY place child transitions fire
    pub fn snapshot(&mut self, buf: &Buffer) -> ViewSnapshots;  // emit → wrap (root-owned) → DisplaySnapshot
}
```
Consequence: a pure cursor move (version unchanged) does NOT reparse — only `sync_cursors` + re-emit run. Reveal changes never bump buffer version (Go invariant, `rev`/D13).

Reveal policies (the `Decide` arm), 1:1 with Go (`span_metadata.go:4-22`, `markdown_block.go:373-375`):

| Machine | Decide policy |
|---|---|
| Heading, Hr, Blockquote (per line), ListItem/Task marker | `cursors.any_on_line(line)` |

### Msg/Cmd runtime (rune-tui/src/{runtime,term}.rs)

ratatui ships no runtime — hand-write Elm-style:

```rust
pub enum Msg {
    Key(KeyInput), Paste(String), Resize(u16, u16),
    ClipboardRead(String), SaveDone { version: u64, result: Result<(), String> },
    ConfirmTimeout { gen: u32 }, Error(String), Quit,
}
pub type Cmd = Box<dyn FnOnce() -> Option<Msg> + Send + 'static>;

/// What one update() call asks the runtime to do. `raw` is the ONLY path by
/// which escape bytes (OSC 52 clipboard writes) reach the terminal: the main
/// loop drains it on its own thread, where it exclusively owns the terminal.
/// Cmds NEVER touch the terminal (termina's Terminal is io::Write on &mut self,
/// single-owner, undocumented for cross-thread use — don't share it).
pub struct Effects { pub cmds: Vec<Cmd>, pub raw: Vec<Vec<u8>> }
```

Exactly three threads: (1) main — `recv` then drain `try_iter`, run `update(&mut app, msg, &mut effects)` per message; after the batch: write each `effects.raw` chunk to the terminal writer (`write_all` + `flush` — same thread as `draw`, so raw output and frames are serialized by construction), spawn `effects.cmds`, draw once if dirty (batches paste bursts into one render); (2) input reader — blocking termina event loop → `tx.send`; (3) per-Cmd `std::thread::spawn` (Phase-1 volume: save, pbpaste, one timer — a pool is YAGNI). §5.4 carried over: `update` mutates state directly; Cmd is exclusively off-thread I/O; terminal writes are exclusively main-loop `Effects.raw`.

`term.rs`: RAII guard — raw mode + alt screen + Kitty keyboard enhancement flags (disambiguate-escape-codes + report-alternate-keys, needed for `super+…` chords) + bracketed paste on construction; `Drop` restores everything. Graceful degradation when the terminal lacks Kitty keyboard support (ctrl variants remain bound). `main.rs` wraps the loop in `catch_unwind`; on panic the guard restores the terminal, message to stderr, exit 70.

Per-message editor sync (mirror of `textedit/render.go:11-31`): after update mutations → `doc.sync_content(&buf)` (iff version changed) → `doc.set_width(viewport_width)` → `doc.sync_cursors(&buf, &cursors)` → `doc.snapshot(&buf)` → scroll-to-cursor via `syntax_to_wrap`.

## Gotchas

- **comrak sourcepos is 1-based, end-inclusive, byte columns.** Conversion: `start = line_starts[l-1]+(c-1)`, `end = line_starts[el-1]+ec`. WP0 proves it on nested/CJK/emoji fixtures BEFORE anything is built on it. If columns turn out to be chars for some node type, pin a per-line char→byte remap table in `parse.rs` and keep the spike as the regression test.
- **There is no option that enables AST sourcepos** — do not hunt for one. `parse_document` always fills `Ast.sourcepos` on every node (inline included); `Options.render.sourcepos` gates only `data-sourcepos` attributes in HTML/XML output (its docs.rs description mentions only output — that does NOT mean AST sourcepos is unavailable). The old `experimental_inline_sourcepos` field no longer exists in 0.54.
- **Cmds must never touch the terminal.** termina's `Terminal` is `io::Write` on `&mut self`, owned by the main loop, with no cloneable writer and no documented cross-thread support. All raw escape output (OSC 52) goes through `Effects.raw`, drained by the main loop between message processing and draw. If a step seems to need terminal access from a Cmd, the design is wrong — route bytes through `Effects.raw` or a `Msg`.
- **Rendered (concealed) spans cannot be split byte-wise in wrap** — their visible text ≠ their buffer range. Include whole when overlapping a break (`wrap_map.go:410-424`). Ignoring this corrupts the cell→offset map.
- **Reveal must never bump the buffer version.** Version is the only content-changed signal; `sync_cursors` transitions machines without touching it. Conflating them re-parses on every arrow key.
- **Unfocused → ForceRendered.** Go's `SyncNoReveal`: raw markup must never show when unfocused.
- **`clippy::indexing_slicing` and byte offsets:** every `&content[a..b]` must come from validated/clamped ranges; use the buffer's clamping helpers, don't sprinkle ad-hoc `min()`.
- **libc symbols (all verified on aarch64-apple-darwin, libc 0.2.189):** `libc::renamex_np`, `libc::RENAME_SWAP` (= 0x2), `libc::RENAME_EXCL` (= 0x4) all exist — use them directly, no local constants needed. Go's equivalent lives in `pkg/vfs/exchange_darwin.go:18,34` (`unix.RenamexNp` with `unix.RENAME_SWAP`/`RENAME_EXCL`).
- **Kitty keyboard flags are required for `super+…` chords** and must be popped on exit (the term.rs RAII guard). On terminals without the protocol, super-chords won't arrive — the ctrl alternates in the keymap table are the fallback; don't treat their absence as a bug.
- **`panic = "abort"` is forbidden** (§1.3): the top-level `catch_unwind` + Drop-guard terminal restore is the halt path. Deny-lints keep panics out of edit/render paths in the first place.
- **Bracketed paste vs pbpaste double-paste:** a terminal ⌘V arrives as `Msg::Paste`; in-app `super+v` runs pbpaste. Both funnel through `handle_paste_content`; never handle one event twice.
- **edition 2024 needs a recent stable toolchain** — `rust-toolchain.toml` pins `channel = "stable"`; if the installed stable is too old for edition 2024, fall back to edition 2021 rather than pinning nightly.
- **Go corpus reuse:** the Go fuzz/unit fixtures for buffer and display round-trips live beside the Go sources (`pkg/editor/buffer/buffer_test.go`, `pkg/editor/display/display_test.go`) — port their cases, don't invent weaker ones.

## Assumptions

The user answered the four open questions (location=rust/ in repo; HSM=hand-rolled; scope=Phase 1 only; UTF-8=refuse). Remaining assumptions:

### A1. Paste reads via pbpaste, not OSC 52 read
- Recommendation: pbpaste subprocess (helix's approach), OSC 52 for writes only.
- Pros: works in Terminal.app/iTerm2/kitty without permission prompts; synchronous and deterministic; no async escape-response correlation.
- Cons: deviates from Go rune's pure-OSC52 symmetry; local-machine only (no SSH clipboard read) — irrelevant for a macOS-local editor.

### A2. Performance budget for full reparse
- Recommendation: accept full-buffer reparse per content change (Go does the same); budget median full pipeline (parse+tree+emit+wrap) < 16 ms on a 5k-line doc on Apple Silicon, measured in WP10.
- Pros: simplest correct design; matches Go's proven architecture.
- Cons: if the benchmark misses the budget, incremental/block-level reparse becomes a follow-up (comrak sourcepos gives block boundaries) — recorded in WP10, not built now.

### A3. Missing-file argument creates an empty buffer
- Recommendation: `rune new.md` on a nonexistent path opens an empty buffer; the file is created on first ⌘S via RENAME_EXCL.
- Pros: matches editor convention; exercises the EXCL publish path.
- Cons: a typo'd filename silently opens empty — acceptable, Go rune behaves comparably for new paths.

## Risks

- **comrak inline-sourcepos infidelity on some node kind** → the markdown choice is void for that construct. Mitigation: WP0 is a blocking spike covering nested bold-link, wikilink, CJK, emoji (ZWJ family), tasklist, fence; runs before any dependent code.
- **Reparse cost blows the frame budget on large docs** → Mitigation: WP10 criterion benchmark + an `#[ignore]`d release-profile guard test (`full_pipeline_5k_under_100ms`, run single-threaded via WP10's explicit invocation only — never inside the parallel debug `cargo test`, where a wall-clock bound flakes); incremental reparse is the named fallback, not a rewrite.
- **ratatui-termina 0.1.0 is young** (first release) → backend integration may have gaps. Mitigation: WP5 brings up the real terminal early; fallback is implementing ratatui's `Backend` trait over termina directly in `term.rs` (small, helix proves termina itself is production-grade).
- **OSC 52 write silently no-ops on some terminal** → copy appears broken. ACCEPTED for Phase 1 (Go rune has the identical behavior — it emits OSC 52 unconditionally; its capability flag is dead code).
- **Undo journal is memory-only** → a crash loses undo history and unsaved work. ACCEPTED by scope decision (recovery store is Phase 2); the quit-confirm warning states it.
